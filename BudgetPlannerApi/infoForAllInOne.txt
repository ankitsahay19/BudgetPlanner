How this satisfies your requirements

Both Swagger UI and MVC routes are available simultaneously:
Swagger: http://localhost:5001/swagger (unchanged)
MVC index: http://localhost:5001/ (Home/Index)
The MVC Index will serve your React app if you copy the React production build files into wwwroot (for example: wwwroot/index.html plus the static assets). This keeps the app following an MVC architecture (you can add more controllers and views) while letting React be the client app served by the same host.
SPA behavior: client-side routes will work because of MapFallbackToFile("index.html") — any unknown route will return index.html so React Router can handle it.

Notes and edge-cases

If you use hashed filenames (CRA default), the Index will reference them correctly only if the React build's index.html is present in wwwroot with matching asset paths.
In development, you might prefer to run React dev server separately (npm start) and keep backend separate. For production, copying the build into wwwroot is common.
If you want to render server-side Razor views that also host parts of React, we can create a Razor view that includes the React bundles. That requires editing the view to include correct script/style tags.
